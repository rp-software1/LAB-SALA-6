  Usando el Github se puede llegar a acceder mas rapido y no depender de una pantalla de carga
  solamente usando un enlance de URL para abrirlo de manera mas rapida. No dependiendo de varias carpetas

  de nuestro programa y seguir avanzando.

  git add: El git add sirve para seleccionar la carpeta que vamos a usar o preparar el guardado.
  git commit: El git commit sirve para guardar los avances que estamos haciendo en el programa en las carpetas.
  git push: Sirve para enviar todos nuestros avances al GitHub.
