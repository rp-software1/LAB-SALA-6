Estudiante Luis

1. ¿Qué hace main.jsx exactamente? ¿Qué pasaría si lo borraras del proyecto?
main.jsx es el punto de entrada de React. Importa App, busca el elemento root del HTML y utiliza createRoot() 
para mostrar la aplicación. Si lo borrara, React no tendría el archivo que inicia y monta la aplicación, por 
lo que el proyecto no funcionaría correctamente.

2. ¿Por qué PlatoCard vive en components/ y Home vive en pages/? ¿Cuál es la diferencia concreta entre los dos?
PlatoCard vive en components/ porque es una pieza reutilizable que podemos usar para mostrar diferentes 
platos. Home vive en pages/ porque representa una página completa que puede contener varios componentes. La diferencia
es que components/ contiene piezas reutilizables y pages/ contiene vistas completas.

3. En el Día 1 usabas import { platosMock } from "./data/platos.mock.js". ¿Por qué ese import funciona ahora con Vite 
y no funcionaba con el CDN del Día 1?
Ahora funciona porque Vite utiliza módulos ES y puede resolver las rutas de archivos del proyecto, permitiendo usar 
import y export. Con CDN cargábamos React desde una dirección externa y no teníamos el mismo sistema de módulos locales
que proporciona Vite.

4. hooks/, services/ y context/ están vacías hoy. ¿Qué va a vivir en cada una y desde qué día del proyecto se van a usar?
En hooks/ estarán los hooks personalizados para reutilizar lógica de React, en services/ estarán las funciones para comunicarse
con la API y en context/ estarán los Context para compartir estados o datos entre componentes. Se utilizarán cuando el proyecto 
necesite esas funcionalidades en los siguientes días.
