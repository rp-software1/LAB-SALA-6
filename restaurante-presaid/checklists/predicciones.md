PREDICCIÓN 1

¿Qué comandos ejecutará Gemini CLI para crear el proyecto NestJS? 
Gemini CLI ejecutará el comando npx @nestjs/cli new restaurante-presaid --package-
manager npm (o nest new restaurante-presaid).

¿Instalará el CLI de NestJS primero? ¿Cuántos archivos creará?
No requerirá instalar globalmente el CLI de NestJS primero, ya que utilizará npx para 
ejecutar la última versión disponible de forma directa.

Creará un proyecto estándar de NestJS con aproximadamente 21 a 23 archivos iniciales 
(incluyendo la estructura de src/, archivos de configuración de TypeScript, Linter, Prettier,
 Git y package.json).
