Día 1:
La transición de React Router DOM a Next.js App Router marcó un cambio fundamental en la forma de conceptualizar la arquitectura de la aplicación, pasando de un enrutamiento basado en un archivo centralizado a un sistema basado en directorios y carpetas físicas. La migración del componente NavBar exigió comprender la distinción técnica entre Server Components y Client Components, incorporando la directiva use client y utilizando el hook usePathname para gestionar dinámicamente las clases de estilo activas. Asimismo, la configuración inicial del proyecto con TypeScript y la creación de rutas estáticas junto con la página personalizada de error not-found.tsx permitieron consolidar una base sólida para el desarrollo del sistema de restaurante.
